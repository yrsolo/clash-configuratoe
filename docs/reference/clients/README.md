# Подключение устройств

Сначала настройте [свою подписку и публикацию](../starter-configuration.md). На устройство передаётся **YAML URL** вида `https://ВАШ-ДОМЕН/api/published/yaml?id=…&token=…`. Ссылка `/?published=…` открывает редактор и не подходит для импорта подписки. JSON проекта нужен редактору, не клиенту.

| Платформа | Клиент для этой инструкции | Инструкция |
| --- | --- | --- |
| Windows | Clash Verge Rev, ядро Mihomo | [Windows](windows.md) |
| macOS | Clash Verge Rev, ядро Mihomo | [macOS](macos.md) |
| Android | FlClash, ядро Mihomo/Clash.Meta | [Android](android.md) |
| iOS/iPadOS | Stash, собственная совместимая конфигурация | [iOS](ios.md) |

Проекты клиентов и ссылки загрузки сверены 7 октября 2026 года. Выбирайте stable-релиз в официальном репозитории/магазине. Поддерживаемые ОС и архитектуры меняются; актуальные требования берите на странице релиза. Android/iOS-версии Clash Verge Rev в этой инструкции не используются.

## Одинаковый порядок проверки

1. Загрузите опубликованный YAML. Внутри должны быть реальные серверы, группы и правила, а не HTML/JSON/заглушки.
2. Сделайте импортированную конфигурацию активной.
3. Выберите режим `Rule`/«Правила». `Global` не следует вашей раскладке правил, `Direct` отправляет всё напрямую.
4. В группах AI, Telegram и видео выберите сервер вручную: начальным выбором может быть `DIRECT`. В `DIR` оставьте `DIRECT`.
5. Включите системный proxy либо VPN/TUN согласно платформе.
6. Проверьте проксируемый сайт, российский/локальный сайт и фактический маршрут в Connections/журнале клиента. Тест задержки не гарантирует доступность каждого сервиса.
7. Изменения применяются в два этапа: обновление публикации редактором, затем обновление удалённого профиля устройством. Интервал автообновления клиента не задаётся интервалом источника внутри JSON.

Сначала проверяйте одну подписку и один сервер. Не подключайте одновременно несколько VPN/TUN-клиентов. System proxy охватывает приложения, которые его соблюдают; для всего трафика обычно нужен TUN/VPN. DNS и маршруты должны согласовываться с выбранным режимом. Windows-имена процессов не переносятся автоматически на другие системы.

QR публикации содержит URL. Обычная камера может просто открыть YAML в браузере; если клиент не поддерживает такой QR-импорт, копируйте ссылку в импорт удалённого профиля. Ссылка содержит токен доступа к конфигурации, поэтому её не следует выкладывать в общий чат или публичные скриншоты.

Если профиль перестал работать, отключите клиент, проверьте сам URL через обычное подключение, убедитесь, что публикация обновляется, и только затем меняйте сервер/DNS. Подробная [диагностика](../operations.md).
