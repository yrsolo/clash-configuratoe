# macOS: Clash Verge Rev

## Установка

Откройте [официальный stable-релиз](https://github.com/clash-verge-rev/clash-verge-rev/releases/latest). Для Mac с Apple Silicon выбирайте ARM/aarch64-пакет, для Intel — x64. Откройте DMG и перенесите приложение в Applications. Запустите его и подтвердите штатные запросы macOS для доверенного скачанного приложения. Не выключайте Gatekeeper целиком ради запуска. Поддерживаемые системы и сборки перечислены в [репозитории проекта](https://github.com/clash-verge-rev/clash-verge-rev).

## Подключение

1. Из своего редактора возьмите обновлённый **YAML URL**.
2. Откройте Profiles/«Профили», добавьте удалённую конфигурацию по этому URL и выберите её активной.
3. Включите `Rule`. В AI, Telegram и видео выберите сервер, в `DIR` — `DIRECT`.
4. Включите System Proxy для проверки браузера. Если клиент запрашивает helper/service component, выполните установку из настроек клиента и подтвердите пароль администратора.
5. Проверьте Connections и сайт, который входит в ваши правила. Открытие сайта само по себе не доказывает прокси-маршрут, если в группе выбран `DIRECT`.

Способы импорта — в [официальной документации профилей](https://www.clashverge.dev/guide/profile.html).

## TUN и локальные исключения

Приложения, которые игнорируют системный proxy, требуют TUN. Включите его в клиенте после установки служебного компонента и выдачи запрошенных прав. Не оставляйте одновременно активными другой VPN и Clash TUN. Если система управляется организацией, права/ограничения могут задаваться администратором.

Windows-правила `PROCESS-NAME,*.exe` на Mac не совпадут. Создайте отдельную копию проекта для macOS и замените их на фактические имена исполняемых процессов, которые показывает клиент. Для qBittorrent/Transmission предварительно проверьте маршрут в журнале, затем добавьте соответствующее правило в `DIR`. При этом доменные правила Telegram/YouTube/AI остаются применимыми независимо от имени процесса.

Приватные сети и Tailscale уже направлены в `DIR` стартовой схемы; TUN и другой сетевой софт всё равно могут конфликтовать на уровне маршрутов. Проверьте локальные ресурсы отдельно. DNS/TUN-параметры задаются клиентом: редактор генерирует маршрутизацию, а не полный профиль системного сетевого интерфейса.

## Обновление и неполадки

Обновите публикацию редактором и затем профиль в клиенте. Параметры самого приложения смотрите в [quick start](https://www.clashverge.dev/guide/quickstart.html). После смены Wi-Fi/проводной сети повторно проверьте system proxy и доступность сервера.

Если proxy остался после закрытия приложения, вернитесь в клиент, выключите его штатно; при необходимости проверьте macOS → System Settings → Network → текущий интерфейс → Proxies. Если работает IP, но не домены, проверяйте DNS. Если TUN не запускается, сначала проверяйте helper и права, затем конфликт с другим VPN. Не отключайте проверку HTTPS-сертификатов как постоянное решение. [Общая диагностика](../operations.md).
