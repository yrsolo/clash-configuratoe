# Windows: Clash Verge Rev

## Установка

1. Откройте [официальные stable releases](https://github.com/clash-verge-rev/clash-verge-rev/releases/latest). Выберите Windows-пакет под архитектуру устройства, обычно x64. Требования и доступные сборки смотрите в самом релизе.
2. Скачайте installer, установите клиент и запустите его. Если установщик предлагает компонент для системной службы, установите его для последующего TUN-режима.
3. Проверьте, что другой VPN/Clash-клиент остановлен. Не импортируйте случайные конфигурации из страницы загрузки.

Источник клиента и поддерживаемые платформы: [репозиторий Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev).

## Импорт и первый запуск

1. В редакторе выполните `Refresh stable publish link` и скопируйте **YAML URL**.
2. В Clash Verge Rev откройте Profiles/«Профили»/«Подписки», создайте удалённый профиль из URL, назовите его `My Clash` и загрузите.
3. Сделайте карточку профиля активной. Если вместо списка серверов появилась ошибка парсинга, проверьте URL и версию ядра прежде, чем менять правила.
4. Включите режим `Rule`. В разделе Proxies/«Прокси» раскройте AI, Telegram и видео, выберите нужные серверы; в `DIR` оставьте `DIRECT`.
5. Для начальной проверки браузера включите **System Proxy**. Откройте сайт из AI-группы и проверьте Connections: цель должна соответствовать выбранному серверу.

Импорт по URL и локальные профили описаны в [документации клиента](https://www.clashverge.dev/guide/profile.html). Названия кнопок зависят от языка/версии.

## TUN и маршрутизация приложений

Если приложение игнорирует system proxy или нужны правила торрент-процессов, включите TUN. Выполните запрос установки/запуска service mode и подтвердите системный запрос прав. Проверьте в статусе клиента, что TUN действительно запущен. Для автоматического поиска процесса может потребоваться настройка ядра `find-process-mode` в глобальных overrides клиента; она не хранится в JSON этого редактора.

Проверьте торрент-клиент в Connections: `qbittorrent.exe`, `uTorrent.exe`, `Transmission.exe` в стартовой схеме идут через `DIR`. Загрузка файла при этом использует прямой адрес устройства. Правило сработает только при совпадении имени и доступности определения процесса. Сайт торрент-каталога отдельно направлен в `TORRENTS`.

Не редактируйте скачанный профиль как единственный источник изменений: следующее обновление заменит его. Редактируйте группы/правила в редакторе, а настройки TUN, DNS, system proxy и запуска — в клиенте. Первый запуск клиента см. также в [официальном quick start](https://www.clashverge.dev/guide/quickstart.html).

## Обновление и восстановление

После `Refresh stable publish link` выполните Update/«Обновить» на карточке профиля. Сохраните разумный интервал обновления удалённой подписки, например раз в час, если ваша версия предлагает его. Обновляйте клиент из того же официального источника.

Если после завершения приложения интернет пропал, откройте Windows → Параметры → Сеть и Интернет → Прокси и проверьте, не остался ли включённый ручной proxy `127.0.0.1`. В штатном режиме сначала выключайте System Proxy/TUN из самого клиента. Ошибка `address already in use` означает конфликт локального порта; остановите другой клиент или смените порт в настройках Clash Verge Rev. Для DNS/сертификата/протокола используйте [общую диагностику](../operations.md).
