# iOS/iPadOS: Stash

На iPhone/iPad эта инструкция использует **Stash**, который импортирует конфигурации Stash/Clash. Это отдельный клиент со своим ядром. Совместимость с форматом не равна полной поддержке всех расширений Mihomo. Документация: [Stash](https://stash.wiki/en), [импорт конфигурации](https://stash.wiki/en/get-started).

## Установка

Откройте официальный сайт/документацию Stash и оттуда страницу приложения в App Store. Проверьте разработчика, требования iOS и доступность для региона своего Apple ID. Условия покупки смотрите в магазине; здесь не фиксируются ни цена, ни доступность. После установки запустите приложение.

## Импорт и запуск

1. Получите **YAML URL** редактора после `Refresh stable publish link`.
2. В Stash откройте Settings → **Configuration File** → **Download from URL**. Вставьте URL целиком и загрузите конфигурацию.
3. Выберите её активной и вернитесь на главную страницу.
4. Нажмите Start. Подтвердите запрос iOS на создание VPN-конфигурации и системную аутентификацию.
5. Используйте режим правил (Rule), а не глобальный прокси/прямой режим. В группах AI, Telegram, видео выберите реальные серверы; в `DIR` — `DIRECT`.
6. Проверьте журнал соединений/правил клиента, сайт из AI-группы и локальный/прямой ресурс. Переключите Wi-Fi на мобильную сеть и повторите проверку.

Порядок Settings → Configuration File → Download from URL → выбор файла → Start дан в [официальном quick start](https://stash.wiki/en/get-started). Названия могут быть переведены в вашей версии.

## Подготовьте отдельный профиль iOS при необходимости

Полная конфигурация из подписки с XHTTP или цепочками `dialer-proxy` должна быть проверена в конкретной версии Stash. В рамках подготовки репозитория установка/соединение на реальном iPhone не проверялись. Если клиент сообщает об unsupported transport/option, выберите совместимый сервер или сделайте отдельный проект с совместимой подпиской; не удаляйте отдельные detour-поля из цепочки наугад.

Windows `PROCESS-NAME` здесь не определяет приложения. Для мобильного проекта используйте домены/IP и проверенные вашим клиентом правила; в копии JSON можно очистить секцию `Process names` соответствующих блоков. Если клиент отвергает GEOSITE/GEOIP/IP-ASN, проверьте документацию ядра и доступность его баз, затем адаптируйте именно неподдерживаемые правила в отдельной копии проекта. Удаление всех правил без анализа меняет маршрутизацию.

Сторонние VPN обычно конкурируют за системную VPN-сессию. Не включайте одновременно Stash и другое VPN-приложение. Правила торрент-трафика Windows не применимы к iOS; VPN-статус не доказывает выбранный маршрут конкретного сервиса.

## Обновление и восстановление

Обновите публикацию редактором и удалённую конфигурацию в Stash. Импорт через AirDrop/Files также поддерживается, но это локальный снимок: для регулярного обновления нужен URL-профиль. Если после смены сети пропал доступ, остановите VPN, проверьте загрузку URL, снова запустите Stash и смените сервер при необходимости. После смены домена приложения обновите URL на устройстве. [Общая диагностика](../operations.md).
