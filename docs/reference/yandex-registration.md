# Первая регистрация в Яндекс Облаке

Инструкция для нового владельца аккаунта, до создания ресурсов проекта. Проверено по официальной документации 7 октября 2026 года; названия экранов и условия оплаты могут изменяться.

## 1. Подготовьте личный аккаунт

Вам нужны Яндекс ID, доступ к его телефону/почте и подходящий способ оплаты для вашей страны. Включите двухфакторную защиту и сохраните способы восстановления. Не используйте аккаунт автора проекта: облако, подписки и платежи должны принадлежать вам.

## 2. Создайте организацию и платёжный аккаунт

1. Откройте [консоль Яндекс Облака](https://console.yandex.cloud/) и войдите в свой Яндекс ID.
2. Перейдите в Yandex Identity Hub и создайте организацию с понятным именем, например `Personal Clash`. По текущему процессу вместе с ней создаётся каталог `default`.
3. Откройте Yandex Cloud Billing. Нажмите создание платёжного аккаунта.
4. Выберите тип плательщика: физическое лицо либо юридическое лицо/ИП, затем страну и контактные данные.
5. Выберите доступный способ оплаты, выполните проверку и дождитесь активации аккаунта. Укажите реальные данные владельца.

На дату проверки новые физические лица начинают с платного потребления; прежнюю схему «сначала бесплатный пробный период» использовать как обещание нельзя. Стартовый грант и право на него зависят от условий регистрации. Проверяйте условия на экране до подтверждения. Основание: [официальная регистрация аккаунта](https://yandex.cloud/ru/docs/billing/quickstart/).

## 3. Выберите облако и отдельный каталог проекта

В консоли проверьте доступное облако и его связь с активным платёжным аккаунтом. Если нужно, создайте собственное облако в организации. Внутри облака создайте отдельный каталог `clash-configurator`, чтобы отделить ресурсы и расходы от других проектов. Сохраните **Cloud ID** и **Folder ID** в своих локальных заметках. Каталог `default` можно использовать, но отдельный проще обслуживать. См. [создание каталога](https://yandex.cloud/ru/docs/resource-manager/operations/folder/create).

## 4. Настройте уведомления о расходах

В Billing выберите платёжный аккаунт → **Бюджеты** → создание бюджета. Выберите тип «К оплате», месячный период, удобную сумму и каталог проекта как область. Добавьте себя как получателя и несколько порогов, например 50%, 80%, 100%. Бюджет отправляет уведомления; сам по себе он не останавливает все ресурсы. См. [настройку бюджетов](https://yandex.cloud/ru/docs/billing/operations/budgets).

Для проекта нужны Object Storage, Cloud Functions, API Gateway и их журналы. Выделенный сервер и Kubernetes не нужны. Проверяйте текущие тарифы и фактическое потребление в Billing; фиксированную стоимость в месяц эта инструкция не обещает.

## 5. Подготовьте CLI

Установите актуальный `yc` по [официальной инструкции](https://yandex.cloud/ru/docs/cli/quickstart), затем откройте новый терминал:

```powershell
yc --version
yc init
yc resource-manager cloud list
yc resource-manager folder list
```

При `yc init` выберите свой аккаунт, облако и каталог. При нескольких аккаунтах создайте отдельный профиль для этого проекта. По текущей инструкции CLI может открывать браузер для входа; OAuth-токен из старых руководств не нужно автоматически переносить в команды. Не публикуйте вывод `yc config list`: настройки могут содержать данные аутентификации.

Если выбран неверный каталог, задайте его явно:

```powershell
yc config set folder-id YOUR_FOLDER_ID
```

`YOUR_FOLDER_ID` здесь и далее — обозначение, которое надо заменить своим значением.

## 6. Проверьте готовность

Вы видите нужную организацию, облако и каталог, платёжный аккаунт активен, уведомления настроены, `yc resource-manager folder list` выполняется. У владельца/администратора есть права создавать ресурсы и назначать роли сервисным аккаунтам. Сами сервисные аккаунты, ключи, бакеты и функцию создавайте уже по [инструкции деплоя](yandex-deploy.md).
