# Базовая конфигурация и свои подписки

Стартовый проект [default/new.json](../../default/new.json) подготовлен по предоставленной актуальной конфигурации владельца. Он автоматически открывается для нового локального черновика; существующие черновики и облачные проекты не заменяются. Для ручного восстановления вставьте содержимое JSON-файла в **Import JSON / YAML** и нажмите **Import into graph**. YAML предназначен для Clash-конфигураций, JSON проекта сохраняет также холст и связи. Импорт создаёт новый ID проекта и timestamps, чтобы не перезаписать старую публикацию; ID узлов/панелей и связи сохраняются.

## Что сохранено и что изменено

Сохранены 35 узлов, шесть панелей, группировка сервисов, фильтры источников и включённые/выключенные блоки правил. Личные URL, UUID доступа, IP сервера, логины, пароли, комментарии источников и домен formatter удалены. Подписки переименованы в `Subscription 1…4`, с ключами `source_1…4`; HTTP- и VLESS-источники стали необязательными выключенными заглушками.

Все источники изначально выключены, а группы допускают `DIRECT`. Это даёт открывающийся без подписок проект, но **не даёт проксирования**. После добавления серверов выберите их в клиенте и при необходимости уберите прямой вариант из отдельных групп.

Убраны повторные связи «правило → группа», когда то же правило уже наследует ту же цель через панель; списки внутри блоков очищены от точных дублей. Добавлены приватные IPv4/IPv6-сети в прямой локальный блок, исключён слишком общий процесс `Updater.exe` из Telegram, удалён неподдерживаемый `GEOSITE,ru`, если он встречался. Отключённый специализированный блок `higgsfield` сохранён как необязательный пример.

## Группы маршрутизации

| Группа | Назначение | После ввода подписок |
| --- | --- | --- |
| `DIR` | Локальная сеть, Яндекс Диск, российские банки/сервисы, Tailscale и процессы торрент-клиентов | Оставьте `DIRECT`, не подключайте прокси к этой группе без отдельной причины |
| `🤖 AI_SERVICES` | AI и связанные сервисы | Выберите подходящий сервер; доступность зависит от страны и самого сервиса |
| `📺 VIDEO_CONTENT` | YouTube, Meta и другие правила медиапанели | Выберите нужный сервер |
| `📢 TELEGA` | Telegram: домены, IP/ASN и процессы | Выберите сервер, затем можно убрать `DIRECT`; custom URL используется только при включённом автоотборе |
| `🏴‍☠️ TORRENTS` | Сайты торрент-каталогов | Выберите сервер, которому разрешён такой трафик |
| `🌍 REST_OF_WORLD` | Всё, что не попало в более ранние правила | Последний `MATCH`; можно выбрать сервер или `DIRECT` |
| `higgsfield_ai` | Необязательное специализированное направление | Включайте вместе с нужным блоком правил |

Торрент-сайты и сам обмен файлами специально различаются. Процессы `qbittorrent.exe`, `uTorrent.exe`, `Transmission.exe` направлены в `DIR`. Это не скрывает адрес при скачивании. На macOS/Android имена процессов и возможности определения приложения отличаются; на iOS Windows-правила процессов применять нельзя. Подробности — в [инструкциях клиентов](clients/README.md).

## 1. Добавьте первую подписку

1. Откройте свой развёрнутый редактор по HTTPS. Для сохранения между устройствами введите имя и длинный случайный код доступа. Держите этот код в менеджере паролей: обычного восстановления пароля здесь нет.
2. Выберите `Global Settings`. Formatter URL должен быть `https://ВАШ-ДОМЕН/api/formatter`. Новый проект получает его из текущего адреса браузера. Для импортированного/старого проекта проверьте поле вручную.
3. Выберите нужный `Subscription N`. Замените URL целиком своей ссылкой, включая её query-параметры. Ключ provider должен быть уникальным. Ни `.invalid`, ни адрес страницы покупки не являются подпиской.
4. Выберите **Формат подписки**. `Clash YAML (подписки для Happ)` подходит, когда провайдер отдаёт YAML с непустым `proxies` (в том числе по Clash User-Agent). `Стандартный (VLESS / Xray)` используйте для поддерживаемой старой подписки/туннельного JSON. Для готового YAML без преобразования в стандартном режиме можно выключить `Use formatter`. Не меняйте формат наугад, если источник вернул HTML/ошибку.
5. Включите узел источника. Откройте список серверов двойным щелчком. Он сначала загружает список без сетевых проб; `Run probe` запускает проверку отдельно из облака.
6. Проследите связи от источника через Merge до нужных групп. Источники не обязаны идти во все группы. Отключённые узлы в YAML не экспортируются.

## 2. Настройте фильтры

В базовой схеме есть фильтры по словам `Россия`, `Russia`, `RU`, `Torrent`. Это совпадение по **имени сервера**, не проверка страны и не определение права на торренты. `invert=true` оставляет совпавшие названия; `invert=false` исключает их. Если у нового провайдера другие названия, измените слова либо временно выключите фильтр. Пустой отбор может оставить группу только с `DIRECT`.

Названия серверов получают префикс provider key. При нескольких подписках это помогает отличать одинаковые серверы. Путь к кэшу provider должен быть уникальным для независимых подписок. Поддержка транспортов (Reality, Hysteria2, XHTTP, detour) зависит от версии клиентского ядра; успешное сохранение JSON не доказывает соединение.

## 3. Сохраните и опубликуйте

Сохраните проект в workspace, получите стабильный YAML URL и выполните `Refresh stable publish link`. Передайте клиенту **YAML URL**, а не share URL редактора. Гостевая публикация создаёт снимок; для ежедневного обновления используйте workspace с постоянной ссылкой. Облачная публикация материализует источники в список прокси; исходный локальный экспорт может содержать provider-ссылки. Предпросмотр после обновления показывает результат, который будет отдан по опубликованной ссылке.

Проверьте, что YAML содержит реальные серверы, нужные группы и один завершающий `MATCH,🌍 REST_OF_WORLD`. Проверьте порядок правил: блоки `first` идут впереди, обычные зависят от порядка связей/панелей. Первая совпавшая строка определяет маршрут. Точные дубли внутри разных блоков могут остаться; редактируйте их в редакторе, если меняете приоритеты.

## 4. Выберите маршруты в клиенте

Режим `Rule` применяет группы и правила. После импорта у группы `select` первым вариантом может быть `DIRECT`; явно выберите сервер для AI, Telegram и видео. Флаг `All` у группы редактора обозначает цель последнего `MATCH`, а не глобальный режим клиента. Автоотбор — `url-test`, ручной выбор — `select`.

Экспорт JSON, YAML URL и QR считайте чувствительными: в них могут быть рабочие подписки или реквизиты серверов. Они предназначены вашим устройствам. См. [обслуживание](operations.md).
